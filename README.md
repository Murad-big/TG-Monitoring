# Мониторинг сообщений Telegram

Скрипт на Pyrogram, который получает сообщения доступных аккаунту чатов, пересылает их выбранному получателю и записывает сведения о них в файл. Отправителей из списка исключений пропускает.

Используется пользовательская сессия Telegram, а не токен бота.

## Настройка

Нужны Python и Pyrogram:

```bash
python -m pip install pyrogram
```

Параметры находятся в локальном `config.json`:

| Параметр | Назначение |
| --- | --- |
| `api_id`, `api_hash` | Данные собственного приложения Telegram |
| `username` | Получатель пересылаемых сообщений |
| `id_users` | Числовые идентификаторы отправителей, которых нужно пропускать |
| `proxy` | Необязательные настройки прокси |

В блоке прокси используются `enabled`, `type`, `hostname`, `port` и, при необходимости, `username` и `password`.

```bash
python main.py
```

При первом запуске потребуется авторизация в Telegram. Файл сессии и личные параметры доступа храните локально.

## Результат

Сообщения пересылаются указанному получателю. Название чата, отправитель, идентификаторы, дата и текст дописываются в `messages.json`. Это последовательность отдельных JSON-объектов, а не один JSON-массив.

## Особенности версии

Обработчик подписан на все сообщения аккаунта, без отбора по ключевым словам. В исходнике предполагается наличие `from_user`, поэтому сообщения каналов и некоторые служебные события требуют отдельной обработки. Перед запуском проверьте получателя и исключения, чтобы избежать повторной пересылки собственных уведомлений.

В репозитории также сохранён `TelegramMonitoring.exe`; его соответствие текущему исходнику отдельно не проверялось.
